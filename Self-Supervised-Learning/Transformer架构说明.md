# ECG 房颤检测 Transformer 架构说明 (ConvTransformer)

## 1. 参考论文
当前在 `model/Transformer.py` 中使用的模型结构（CNN + Transformer 联合架构）主要参考了医学领域尤其是心电图（ECG）分析中广泛使用和验证的文献，包括：

1. **"An End-to-End Convolutional Neural Network With Transformer for ECG Arrhythmia Classification"**
   - 证明了结合一维卷积提取局部波形特征与 Transformer 提取全局长程依赖特征在房颤和心律失常分类上的优势。
2. **"ECG Heartbeat Classification using Convolutional Neural Network and Transformer"**
   - 验证了 CNN 与 Transformer 级联在单导联长序列心律失常分类上的有效性，并被作为诸多算法竞赛的 Baseline。
3. **Conformer 架构（卷积增强型 Transformer）在生理电信号中的相关衍生应用**
   - 类似语音识别中的 Conformer，利用卷积补足了纯注意力机制在捕捉细粒度局部形态特征上的短板。

## 2. 为什么原始的“纯 Transformer”效果差？
在先前的版本中，直接将一维的长时间序列（例如成百上千个采样点的高频 ECG 信号）按时间点步送入单一的 Transformer 中，面临两个致命缺陷：
- **缺乏局部归纳偏置**：纯 Transformer 没有卷积网络的局部性原则（Locality），导致它难以有效地捕捉像 `P波`、`QRS波群` 这种小时间范围内的微观形态特征，而这也正是区分正常心跳与其他异常心跳的基础。
- **时间复杂度过高与难以收敛**：Transformer由于其自注意力矩阵计算的特性，时间复杂度是信号长度的平方 $O(N^2)$。面对极长的 ECG 序列，网络很容易发生过拟合并无法学习到有效宏观节奏规律。

## 3. 当前架构 (ConvTransformer) 的运行机制
当前的改进模型将信号处理分为四个递进过程，做到了“宏观与微观”的结合：

### 第一步：局部微观特征提取 (1D-CNN + MaxPool)
利用多层的一维卷积（1D-CNN）串联局部最大池化层。这一步旨在充当“信号放大镜”，在信号的局部扫描中捕获 QRS 复合波形态、T波异常等底层形态学特征。更关键的是，多次池化大幅度降采样了序列总长度（将原始序列长度 L 浓缩为更短的特征序列 L'），极大地降低了后续自注意力计算的负荷。

### 第二步：位置编码 (Positional Encoding)
Transformer 的自注意力机制只关注特征内容而无视“先后顺序”。对于心功能节律而言，时间先后顺序至关重要。因此我们在送入注意网络之前，给降维后的序列追加了标准的三角函数（Sin/Cos）位置编码，赋予模型分辨时间流向的能力。

### 第三步：全局长程节律提取 (Transformer Encoder)
浓缩并附带位置信息的序列特征被输入 Transformer 编码器。在这个阶段，模型不再纠结于具体的波形，可以在全局跨度上对不同节律周期分配注意力权重。房颤（AFib）的经典临床表现是**“RR 间期绝对不整齐”**和**“整体心律不规则”**，多头自注意力（Multi-Head Attention）能够跨越数十个心搏捕捉这种长期、全局的宏观依赖与规律异常。

### 第四步：ViT 式聚合与分类识别 ([CLS] Token & Classifier)
*(注：最新版本已废弃全局池化)* 模型不再使用全局平均池化，而是借鉴了 Vision Transformer (ViT) 的做法，在此阶段提取被专门插入到序列头部的 `[CLS]` Token。这个独特的 Token 已经在多头注意力层中游历了所有的序列节点，自动“吸附”了有用的患病（或正常）节律信息。最终由该 Token 独挑大梁，进入多层感知机（MLP）并通过 Sigmoid 函数得出 $0 \sim 1$ 的最终预测置信度。

## 4. 针对比肩并超越 LSTM 的进一步深度优化 (ViT / Conformer-Lite 机制)
由于医学一维生理电信号天然对时间顺序、局部依赖极为敏感，LSTM 本身通过其门控记忆机制具备极强的“时序归纳偏置”。这导致早期的初步 ConvTransformer 在准确率上升到一定程度后容易遭遇瓶颈甚至下降落后。为了打破这一限制并赋予 Transformer 更稳健的表现（并在交互训练后期顶住漂移，确保攀升至 0.9 左右），我们对模型架构补充了以下几项关键优化：

### 4.1 引入 [CLS] Token 替换全局平均池化 (GAP)
- **原因**：在房颤 (AFib) 检测中，病理特征通常是高度稀疏的（例如长达数千个采样点的记录中，往往只有其中特定的几个 RR 间期发生突变或消失）。如果使用全局平均池化 (GAP)，这些“尖锐且微弱”的异常特征电信号往往会被其余大段的正常电信号时间步所“平均掉（Feature Dilution）”。
- **优化机制**：在时间序列进入 Transformer 之前，我们在最前面显式地拼接了一个可学习的 `[CLS] Token`。注意力机制使得 `[CLS]` 像一块“特征磁铁”，能够通过 Query-Key 计算主动去吸收那些重要的异样时间节点的高维表征，从而避免了平均池化导致的特征埋没。

### 4.2 减轻 CNN 降采样力度，保留足够的“时间颗粒度”
- **原因**：此前过于激进的 1D-CNN 池化压缩（大卷积核、大步幅）导致时间序列在进入 Attention 网络前被缩短过度，剥夺了 Transformer 计算多个心跳与心跳之间关系的时序空间。
- **优化机制**：我们将原本粗犷的卷积核大小缩小为连续递进的 `7 -> 5 -> 3`，且取消了卷积层内部的大跨度步长，仅保留基于池化（MaxPool）的稳态降维。这确保了特征经过提纯后，仍然能够为 Transformer 前端保留数百步长度的充足时序分辨率空间。

### 4.3 升级为可学习的绝对位置编码 (Learnable Positional Encoding)
- **原因**：传统的固定数学三角函数（Sin/Cos）位置编码更适用于非常长且长度动态多变的自然语言处理或机器翻译体系。
- **优化机制**：对于具有高采样频率、相对规范化裁切的心电信号体系，将其替换为完全可训练的分布参数矩阵 (`nn.Parameter`)。在神经网络的反向传播中，网络能自我摸索和微调“第 10 步心跳和第 12 步心跳在生理学上的相对距离与绝对依赖关联”，赋予模型比肩乃至超越 LSTM 时序序列扫描的精细分辨能力。
